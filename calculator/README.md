项目介绍
本项目是使用 Python 编写的命令行交互式计算器，包含完整的异常处理、循环交互、四则运算功能。
符合标准 Python 项目结构，可直接作为 GitHub 作品集展示。
功能特性
支持加法、减法、乘法、除法运算
处理非法输入、除零错误
支持循环计算，无需重复启动程序
代码结构清晰，注释完整，适合学习
